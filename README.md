# ClearStep

Статический сайт (без сборки), публикуется на GitHub Pages как есть.

## Структура
- `index.html`: разметка
- `styles.css`: стили
- `app.js`: логика приложения (тесты, блокнот, повторения, настройки, окна входа)
- `data/curriculum.js`: курсы и модули (сейчас 11)
- `data/questions.js`: банк вопросов (сейчас около 65)
- `js/auth.js`: адаптер Supabase (`window.CS`), единственная точка входа для аккаунтов и облака
- `js/config.js`: публичные настройки Supabase (URL и anon key)
- `js/effects.js`: визуальные эффекты
- `supabase/schema.sql`: таблица, правила доступа (RLS), удаление аккаунта
- `SUPABASE_SETUP.md`: пошаговая настройка

## Запуск локально
```
python3 -m http.server 8000
```
Откройте http://localhost:8000. Через `file://` вход не работает.

## Публикация
Загрузите все файлы в корень репозитория, GitHub Pages: Settings → Pages → ветка main, папка `/`.

## Что сделано на этом этапе
- Код разбит на файлы, поведение прежнее.
- Убраны «Скачать данные» и «Скопировать» из основных настроек. Экспорт и восстановление оставлены в свёрнутом блоке «Конфиденциальность».
- Вход через Supabase: email и пароль (с подтверждением почты и сбросом пароля), Google, ссылка на почту. Смена пароля и удаление аккаунта в настройках.
- Облачный прогресс (таблица `user_progress` с RLS), слияние с локальным прогрессом (дубли попыток отсекаются), статусы Saving / Saved / Offline / Sync error.

## Этап 2: тесты модулей (Unit Test)
- В каждом модуле кнопка «Тест модуля»: 10 разных вопросов из банка этого модуля, без таймера, объяснения только после завершения.
- Результат: процент, разбор каждой ошибки, первая и лучшая попытки, история попыток (`S.ut`, до 50 на модуль, сохраняется в облаке и сливается без дублей).
- Зачёт при 80%. Статусы: Не начат, В процессе, Нужно повторить, Сдан, Освоен (зачёт на двух разных днях).
- Кнопки: пройти тест ещё раз, тренировать только ошибки, повторить урок.
- Проверено в jsdom: 10 разных вопросов из нужного модуля, сохранение попыток, статусы, тренировка по ошибкам, нет ошибок в консоли.

## Ограничения
- Сейчас 9 модулей и 116 вопросов. 48 модулей, тесты разделов и уровней, словарь пока не сделаны.
- Языки: EN и RU. Узбекский пока не добавлен.
- Вход не проверен на реальном проекте Supabase (нужны ваши ключи). Проверена только логика интерфейса в браузере.
- Если открыть сайт с двух устройств одновременно, при каждом входе данные сливаются, но сохраняется блоб целиком: возможна потеря самых свежих действий одного из устройств.
